# Elo Urbano

## Sobre o Projeto

O Elo Urbano é uma plataforma desenvolvida para conectar consumidores, pequenos comerciantes, produtores locais e prestadores de serviço de uma mesma região.

A proposta é fortalecer a economia local através de uma solução digital simples e acessível, permitindo que usuários encontrem produtos e serviços próximos utilizando recursos como geolocalização, catálogo digital e cadastro de fornecedores.

---

## Objetivo

Promover a visibilidade de pequenos negócios locais e facilitar a conexão entre consumidores e fornecedores da comunidade.

Entre os benefícios propostos estão:

- Incentivo ao comércio local;
- Maior visibilidade para pequenos empreendedores;
- Facilidade para encontrar produtos e serviços próximos;
- Redução da dependência de grandes marketplaces;
- Fortalecimento da economia regional.

## Principais Componentes

### Navegação Responsiva

A aplicação possui um menu adaptável para dispositivos móveis utilizando um botão hamburger e controle de exibição por JavaScript.

### Carrossel Informativo

O site apresenta um carrossel com navegação manual e automática para destacar informações importantes sobre a proposta do projeto.

### Scroll Reveal

Elementos da página são exibidos gradualmente conforme entram na área visível do usuário utilizando a Intersection Observer API.

### Formulários

Os formulários foram estruturados para futura integração com APIs e banco de dados.

Atualmente, os envios são simulados apenas no frontend.
